# JavaScript - Manipulação do DOM e Lista de Compras

Este projeto consiste numa aplicação web interativa desenvolvida em **JavaScript**, focada na manipulação dinâmica do DOM, gestão de itens de lista e estruturação modular de scripts para o front-end.

## Tecnologias e Ferramentas Utilizadas

* **Linguagem:** JavaScript (ES6+)
* **Estruturação & Estilização:** HTML5, CSS3
* **Recursos Visuais:** Ícones SVG e ativos gráficos
* **Controle de Versão:** Git, GitHub

Principais Casos Implementados e Funcionalidades
A aplicação contempla interações dinâmicas voltadas para o quotidiano:

Gestão de Lista Dinâmica: Adição, edição e remoção de elementos diretamente na interface web através de manipulação avançada do DOM.

Modularização de Código: Divisão de responsabilidades em múltiplos ficheiros JavaScript (scripts/) para melhor organização e manutenção.

Validação de Estados: Verificação automática para gerir o comportamento visual quando a lista se encontra vazia.
